# Bynge legal pages

Privacy Policy, Terms of Use and Support for the Bynge iOS app, served by
GitHub Pages at https://byngeapp.com/.

The source of truth is the app repository: `docs/legal/` (also bundled into
the app) and `docs/site/` (`.well-known/apple-app-site-association`, which
lets invite and title links open the app, and `404.html`, which GitHub Pages
serves for those links when the app isn't installed). Edit them there and
copy them here.
